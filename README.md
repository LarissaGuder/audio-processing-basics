# Speech and audio processing introduction materials

## Books
### [Introduction to Speech Processing](https://speechprocessingbook.aalto.fi/index.html)
  Book by Tom Bäckström, Okko Räsänen, Abraham Zewoudie, Pablo Pérez Zarazaga, Liisa Koivusalo, Sneha Das, Esteban Gómez Mellado, Mariem Bouafif Mansali, Daniel Ramos, and Mohammad Hassan Vali. This is the most complete book that I found on Speech Processing.

### [Computational Paralinguistics: Emotion, Affect and Personality in Speech and Language Processing](https://vdoc.pub/download/computational-paralinguistics-emotion-affect-and-personality-in-speech-and-language-processing-7b26e9mt58f0)
  Book by Björn W. Schuller and Anton M. Batliner
  This book presents the methods, tools and techniques that are currently being used to recognize (automatically) the affect, emotion, personality and everything else beyond linguistics (‘paralinguistics’) expressed by or embedded in human speech and language. 
  It is the first book to provide such a systematic survey of paralinguistics in speech and language processing. The technology described has evolved mainly from automatic speech and speaker recognition and processing, but it also incorporates recent developments in speech signal processing, machine intelligence, and data mining.
  Moreover, the book offers a hands-on approach by integrating real datasets, software, and open-source utilities, making it invaluable as a teaching tool and useful for professionals already in the field.

### [Audio Signal Processing for Machine Learning](https://www.youtube.com/playlist?list=PL-wATfeyAMNqIee7cH3q1bh4QJFAaeNv0)
  Mini-course from Valerio Velardo on processing raw audio data for audio-driven AI applications.

### [PyTorch for Audio + Music Processing](https://www.youtube.com/playlist?list=PL-wATfeyAMNoirN4idjev6aRu8ISZYVWm)
  Mini-course from Valerio Velardo on PyTorch for building deep learning models, and torchaudio to run efficient audio feature extraction on the GPU.

### [What Everyone Working on Spoken Language Processing Needs to Know about Spoken Language](https://www.youtube.com/playlist?list=PLWa3auHYUrmM)
  Roger K. Moore mini-course presented at Interspeech 2020 about the basics of speech processing
